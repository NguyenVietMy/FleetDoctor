## CI completion

After pushing changes or opening/updating a PR, wait for all CI checks on the latest PR commit to finish and pass before reporting the work complete. If a check fails, inspect its logs, fix the cause, push the fix, and wait for the new checks to pass. Continue giving progress updates while checks run.
